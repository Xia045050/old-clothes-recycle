# 旧衣回收小程序

一个功能完整的「旧衣回收」微信小程序（原生开发，非云开发），复刻了主流旧衣回收类小程序的核心玩法：**免费预约上门回收 + 环保积分 + 附近回收点**。所有数据保存在本机缓存（wx storage），无需后端即可完整体验全部流程。

## 如何运行

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（本项目在 2.02 版本验证通过）。
2. 打开开发者工具 → **导入项目** → 选择本目录（`C:\旧衣服回收小程序`）。
3. AppID 一栏：
   - 有自己注册的小程序 appid 就填自己的；
   - 没有就点 **「测试号」**（推荐，一键生成）；当前配置里临时填了本机另一个项目的 appid（`wxc7a5e24ba0654b1f`），仅用于本地打开，**发布前请务必替换**。
4. 编译即可看到首页，四个底部标签页：首页 / 预约回收 / 我的预约 / 我的。

也可以用命令行打开（需先在开发者工具 设置→安全 设置中开启服务端口）：

```bash
"C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" open --project "C:\旧衣服回收小程序"
```

## 功能清单

| 模块 | 说明 |
| --- | --- |
| 首页 | 品牌宣传、轮播 banner、4 个快捷入口、6 类回收品类、回收流程、服务承诺、底部预约 CTA |
| 预约上门 | 地址选择/新增、回收品类多选、预估重量、未来 7 天日期 + 4 个时间段、备注、预计积分实时显示、表单校验 |
| 我的预约 | 全部/待上门/已完成/已取消 筛选、下拉刷新、空状态 |
| 预约详情 | 状态横幅、四步进度时间线（进行中呼吸动画）、完整预约信息、取消预约、拨打电话 |
| 地址管理 | 列表、新增/编辑（省市区 picker + 手机号校验）、默认地址、删除、选择模式回传预约页 |
| 环保积分 | 积分余额（1kg=5分）、环保贡献（减碳/节水/植树换算）、积分兑换礼品（扣减积分）、积分明细 |
| 附近回收点 | map 组件 + 标记点、网点列表、导航前往（wx.openLocation）、电话咨询 |
| 我的 | 模拟登录、积分/预约数/减碳量统计、功能菜单、重置演示数据 |
| 关于我们 | 品牌介绍、旧衣去向（公益捐赠/环保再生/循环利用）、常见问题、联系方式 |

## 环保换算口径

- 积分：1 公斤旧衣 = 5 积分
- 减碳：每回收 1kg 约减少 3.6kg CO₂ 排放
- 节水：每回收 1kg 约节约 6000L 水
- 植树等效：1 棵树每年吸收约 18.3kg CO₂

（为同类平台通用宣传口径，可在 `utils/store.js` 顶部常量中调整。）

## 接入真实后端

所有数据读写集中在 `utils/store.js`，接口语义为 `getOrders / addOrder / updateOrder / getAddresses / addAddress / ...`。接入真实后端时，把这几个函数内部改成 `wx.request` 调用即可，页面代码无需改动。

## 其他说明

- 「重置演示数据」在 我的 → 底部，可一键恢复初始预约/地址/积分。
- 首页右上角菜单支持「转发给朋友」（已实现 onShareAppMessage）。
- 客服电话、网点坐标均为演示数据，替换 `pages/nearby/nearby.js` 与 `pages/*` 中的号码即可。
